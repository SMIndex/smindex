**[A-54] losing trades and their 5-minute mid path**

```sql
-- trade rows
SELECT id, strategy, model, asset, direction, entry_px, stop_px, target_px, size,
       pnl_gross, fees, pnl_net, mae, mfe, fill_ts, exit_ts, exit_reason
FROM strat_trades WHERE fill_ts >= 1788480000000 ORDER BY fill_ts;

-- 5-minute path for each (per coin, fill_ts..exit_ts)
SELECT MIN(ts), AVG(mid) FROM strat_book_5s
WHERE coin = %s AND ts BETWEEN %s AND %s
GROUP BY FLOOR(ts/300000) ORDER BY 1;
```
Derived R = `pnl_gross / (|entry_px − stop_px| × size)`; derived exit =
`entry_px ± pnl_gross / size`. A trade is a "loser" when derived R ≤ 0.
